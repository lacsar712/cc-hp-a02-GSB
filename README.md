# 饮片炮制记录台

一条记录是一整包炮制文书，里面是工序数组，不是拆成多列指标的普通表单。清炒温度和时长不在范围内就不能放行。

清炒前强制登记浸泡前置：炮制员在浸泡台为某味设浸泡目标分钟并点开始浸泡，服务端以服务器时刻计时；未满目标分钟时该味禁止开炒，写入会被挡下并提示还差多少分钟，满分钟后方可写入，写入即消耗这次浸泡（再炒需重新登记）。改目标分钟只影响未开始的浸泡，已开始的以启动时记下的目标为准。质检员可在浸泡台看进度，不能点开始、不能改目标。

## 验收

1. processor 登录后，甘草为放行，黄芩为未放行（温度过低）。
2. 顶栏进浸泡台：白芍目标设 30 并点开始浸泡，立刻回记录台写白芍清炒，被挡并提示还差 30 分钟。
3. 另取一味（如 白术）目标设 0 并点开始浸泡，立刻写 110 度 10 分钟，写入成功。
4. 已开始浸泡的白芍，把目标改成 5，进行中的白芍仍按 30 分钟计时。
5. checker 登录能看浸泡进度，但浸泡台没有设置目标和开始浸泡的入口，也看不到写入按钮。

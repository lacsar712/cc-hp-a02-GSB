# 饮片炮制记录台

一条记录是一整包炮制文书，里面是工序数组，不是拆成多列指标的普通表单。清炒温度和时长不在范围内就不能放行。

清炒前强制登记浸泡前置：炮制员在顶栏「浸泡台」为某味设置浸泡目标分钟并点开始浸泡，服务端以服务器时刻计时，未满目标分钟该味禁止开炒并提示还差多少分钟，满分钟后方可写入（写入后该次浸泡即消耗，再炒需重新浸泡）。改目标分钟只影响未开始的浸泡，已开始的以启动时记下的目标为准。质检员可查看浸泡进度，不能点开始、不能改目标。

## 验收

1. processor 登录后，甘草为放行，黄芩为未放行（温度过低）。
2. 再写一条温度 200 的清炒，结论仍是未放行。
3. checker 看不到写入按钮。
4. 浸泡台为白芍设目标 30 分钟并点开始浸泡，立刻开炒被挡并提示还差多少分钟。
5. 另开一味设目标 0 分钟并点开始，立刻写 110 度 10 分钟应成功。
6. checker 能看浸泡进度，但看不到保存目标和开始浸泡按钮。
